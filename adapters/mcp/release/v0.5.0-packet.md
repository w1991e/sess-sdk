## What 0.5.0 contains

- The `0.5.0` entry in CHANGELOG.md.
- The runtime SDK dependency, exact: `@sess.si/sdk@0.5.0` from the registry (sha256 `84f6e005a849158d149100358c75d576b0725178f734aa0d7f4ced22e79c7f24`, integrity `sha512-pdHBzdDYt3JGmCs1kWMjKAQfIBzwSzwWDmRAaceX3ES5wtwuxakB6rxCW0nMXc9biF44vTy2rybYfs/9M6MuUg==`; SDK release run 44967680579 on tag `v0.5.0`).

The `sess_request` and `sess_ask` descriptions take their numbers from the same limits (#77).
