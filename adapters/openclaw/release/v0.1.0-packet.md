## Maintainer steps

1. Confirm the reviewed PR carrying this packet is merged and its CI is green on master. Note the
   merged master commit `<sha>` and check that it is version `0.1.0`:
   `git show <sha>:adapters/openclaw/package.json | grep '"version"'`.
2. Tag that exact commit and push the tag (after `mcp-v0.1.0`, before `create-agent-v0.1.0`):

   ```sh
   git tag openclaw-v0.1.0 <sha>
   git push origin openclaw-v0.1.0
   ```

3. The workflow **Publish approved OpenClaw adapter release**
   (`.github/workflows/openclaw-release.yml`) starts. Its prepare job runs the guards and their
   self-test, `npm ci`, build, typecheck, tests, the packed check against the registry SDK and a
   real OpenClaw host, and `npm audit`. It uploads the tested tarball and prints its SHA-256 in the
   run summary. That SHA-256 must equal the value above, and the derived dist-tag must be `latest`.
4. Approve the `npm-openclaw-release` environment for the publish job. It stages exactly the tested
   tarball with provenance on dist-tag `latest` (`npm stage publish`; nothing is installable yet).
5. Check and approve the stage with npm 2FA:

   ```sh
   npm stage list @sess.si/openclaw --json
   npm stage download <stage-id>
   shasum -a 256 sess.si-openclaw-0.1.0-<stage-id>.tgz   # must equal the SHA-256 above
   npm stage view <stage-id>                             # tag must be latest
   npm stage approve <stage-id>                          # npm 2FA
   ```

6. The readback job waits for the approval, then checks version, integrity, the `latest` dist-tag,
   repository and directory, dependencies and peer dependencies, and provenance. If it timed out,
   re-run the failed jobs after approving.
7. Read back yourself:

   ```sh
   npm view @sess.si/openclaw@0.1.0 version dependencies peerDependencies dist.integrity dist.attestations --json
   npm view @sess.si/openclaw dist-tags --json     # latest: 0.1.0; next stays 0.1.0-rc.5
   ```

   `dist.integrity` must equal the integrity above, `dependencies` must name
   `"@sess.si/sdk": "0.1.0"`, `peerDependencies` must equal `{"openclaw":"2026.10.3 || 2026.10.7"}`, and
   `dist.attestations.provenance` must be present.

## After publication

Run a clean native install from the registry on the qualified host
(`openclaw plugins install npm:@sess.si/openclaw@0.1.0`) and record it in a separate reviewed PR,
together with `compatibility.json` `publication` moving to 0.1.0 on `latest`. ClawHub listing is a
separate, separately authorized action (see [RELEASING.md](../RELEASING.md)).
